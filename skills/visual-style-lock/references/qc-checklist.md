# QC checklist

Run before approving any frame. The operator answers each line; the agent presents the frame and waits.

## Element presence (agent-run where the render is visible)
- [ ] Every FIXED element from the STYLE_LOCK element inventory is visibly present — list them by name when running this check (for example: "the desk", "the coffee cup", "the subject's watch").
- [ ] Eyewear and prop shapes match the anchor image, not a secondary reference.
- [ ] No burned-in text, captions, or subtitles appear anywhere in the frame.
- [ ] A missing FIXED element is a FAIL, not a note — re-run it or flag it explicitly.

## Grade
- [ ] Colour and white balance match the grade anchor (not warmer, not cooler, not flatter).
- [ ] Contrast and shadow tone match the dissected spec.
- [ ] No drift word reintroduced (check the STYLE_LOCK discipline note).

## Identity and casting
- [ ] Faces and casting are consistent with the set and the project's representation rule.
- [ ] Wardrobe and key props match the locked spec.

## Branding
- [ ] The logo or mark reproduces exactly; it is not redrawn, recoloured, or distorted.
- [ ] Text and logo policy honoured (only the allowed marks appear in-frame).

## Optics and composition
- [ ] Focus policy correct (for example deep focus, no unwanted bokeh).
- [ ] Framing leaves the space the destination needs (headroom or clear area for type).
- [ ] Posing matches the rule (for example natural and unposed).

## Technical
- [ ] Aspect ratio correct for the destination.
- [ ] Resolution correct for the stage (1k for test and composition; hi-res only for an approved final).

## Set coherence
- [ ] Placed beside the rest of the set, this frame reads as the same shoot.
