## 1. Pilot design

1. **Hypothesis:** on large / low-judgment / machine-verifiable jobs, Hermes on free non-Anthropic backends cuts Anthropic usage-window tokens ≥30% at equal-or-better pass rate. Nothing else is tested.
2. **Containment:** every Hermes terminal runs inside a container (`terminal.backend: docker`) on **Colima**, using **our own image** (digest-pinned official `python:3.11-slim` + git/shellcheck/ripgrep/jq). The job workdir is the only WRITABLE mount (v2.1s: Hermes additionally ro-mounts credential files, `$HH/skills` and its cache dirs on every container — `tools/environments/docker.py`). **Container egress is dropped at the VM level** (`iptables -I DOCKER-USER -j DROP` inside the Colima VM, re-applied by the engine script on every start) — containers cannot reach the internet, the host (`host.docker.internal`), or each other; T11 measures this from inside a container. The host-side Hermes process (the only thing that needs egress) runs behind an **allow-list proxy** that logs every CONNECT (Groq arms: `api.groq.com:443` only; Ollama arms: deny-all) with a positive control proving the proxy binds. A **sha256 integrity manifest** (`$HQ` tracked contents, `$PT` tracked contents, `~/.claude` minus transcripts, `~/.ssh`, `~/.gitconfig`, `~/.local/bin`, `~/Library/LaunchAgents`, `crontab -l`, shell rc files, `$HH/config.yaml`, `$HH/skills`) is taken before/after every run; any delta outside the job workdir = run FAIL + `$PR/HALT`.
3. **Anthropic path — the control and its corroboration:** the impersonating provider code is **removed from the pinned checkout** (T3) and a source census proves no live path remains (T10 part 1) — that is the control. The dynamic tests (decoy `security` shim, securityd log with `--info --debug` + a positive control, a trap-unlocked locked-Keychain window, deny-all proxy) are corroboration, and the proof document says so. The Keychain item `Claude Code-credentials` is present on this Mac; `~/.claude/.credentials.json` is not.
4. **Measurement (pre-registered — written to the board in T13 BEFORE any run and never edited after):** one fresh `sonnet` subagent per arm per job with the identical `brief.md`; arm A direct, arm B via the wrapper; the arm's whole transcript is its cost. J1's saving = A vs **B (Ollama)**; J1-C (Groq) is a secondary observation. Verdict computed on BOTH `window_tokens = input + cache_creation + output` AND `window_tokens_incl_cache_read`; they must agree, else that job is INCONCLUSIVE. Rerun (±10 pp zone) reruns BOTH arms; the mean of both runs is used. Rate-limited runs are VOID (not FAIL) and are retried; **all attempts' tokens are summed** into the arm's cost. **An INCONCLUSIVE job contributes 0 % saving** to the median. If no Groq key exists by S3, J2 and J3 run on Ollama; still n = 3.
5. **Kill rule:** DROP unless the median saving across J1–J3 is ≥30 % on both metrics AND arm-B pass rate ≥ arm-A pass rate. DROP triggers T23. KEEP proposes named auto-mode for `hermes-bulk` + a Stage-2 BACKLOG item.
6. **Hard kills (any ticket, any time):** any live Anthropic path found by the census; any `security`-shim hit or securityd line naming `Claude Code-credentials`; any integrity delta outside the workdir; any container egress observed in T11; any `hermes skills install` / `hermes update` / `import-agent`; any background Hermes process. Stop, write `$PR/HALT`, do not continue.
7. **Backends:** Ollama `hq-coder-64k` (model chosen in T7 so that 64k context FITS with Colima up — Hermes rejects <64k at startup; there is NO 32k fallback) and one Groq model chosen from live rate-limit headers.
8. **Explicitly NOT built:** gateway/launchd/cron/kanban/heartbeat/goals/loops/Telegram; MCP bridge; auto-mode routing; Hermes memory/skill writes; Paperclip smoke; git worktrees for jobs; doctrine edits before T22; cost-ledger schema migration (side table only); Docker Desktop GUI use.
9. **Honest cost note:** the pilot spends more window than it saves in 14 days (realistic **2.6–4.4M** tokens incl. foreman boot). The payoff is a doctrine decision.
10. **Mode:** foreman PROPOSES every Hermes hand-off; no auto-routing until T22 grants it by name (Lesson 17).
11. **Verification backstop:** every verifier ticket is preceded by a commit on `hermes-pilot` (in `$PT`, **explicit pathspecs only — never `-a` or `.`**); after the verifier returns, `git -C $PT status --porcelain` clean + HEAD unchanged, else the verification is void. Landing = the operator merges `hermes-pilot` → `main` via `/sync` at GATE C, **after T22** (Lesson 32).
12. **Gates:** GATE 0 done (this revision) · GATE A after T11 = `/ctdd-precheck` + `/proof-check` · GATE B after T16 = same · **GATE C = operator landing after T22** · T23 only on DROP, after landing.
